* A ideia

VLMs tradicionais retornam *texto livre*: você pergunta "o que tem nessa imagem?"
e recebe um parágrafo descritivo. Depois precisa *parsear* esse texto com regex,
LLM secundário, ou código frágil pra extrair dados.

O *LFM2.5-VL-Extract* faz diferente: você passa uma imagem + uma lista de campos
(em YAML), e ele devolve *JSON estruturado* direto. Sem camada de parsing.

Isso é um **LLM de propósito específico**: não precisa de frontier model pra
tudo. Pra extração estruturada, 1.6B bastam.

* Definir os campos

O system prompt descreve os campos em YAML — o modelo usa isso como schema:

#+BEGIN_SRC python
SYSTEM_PROMPT = """You are an extraction model. Extract the following fields from the image and return them as JSON:
text_title: The title of the document
author: The author's name or source
subject: The subject or topic
word_count_approx: Approximate word count"""

print("✅ Schema definido!")
#+END_SRC

* Extrair dados da imagem

#+BEGIN_SRC python
import requests, json, base64, time

LLM_URL = "http://localhost:12434/v1/chat/completions"
MODEL = "lfm2.5-vl-1.6b-extract"
IMG_PATH = "/home/alchemist/git/sprachspiel/assets/mixed/redacao.png"

with open(IMG_PATH, "rb") as f:
    img_b64 = base64.b64encode(f.read()).decode()

payload = {
    "model": MODEL,
    "messages": [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": [
            {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{img_b64}"}},
            {"type": "text", "text": "Extract the fields from this document."}
        ]}
    ],
    "max_tokens": 512,
    "temperature": 0.1
}

start = time.time()
response = requests.post(LLM_URL, json=payload, timeout=60)
elapsed = time.time() - start

data = response.json()
content = data["choices"][0]["message"]["content"]
tokens = data.get("usage", {}).get("completion_tokens", "?")

print(f"⏱️  {elapsed:.1f}s ({tokens} tokens)")
print()
result = json.loads(content)
for key, value in result.items():
    print(f"  {key}: {value}")
#+END_SRC

* Comparação: VLM genérico vs Extract

- *VLM genérico* (e.g. Gemma4-2B): devolve texto livre → precisa parsear depois
- *Extract*: devolve JSON → já tá pronto pra consumo por código/pipline

* Resumo

- **LFM2.5-VL-Extract** é um VLM de *propósito específico*: extração estruturada
- Passa imagem + YAML fields → recebe JSON, sem camada de parsing
- **1.6B params**, roda em qualquer GPU com 3 GB VRAM
- Não precisa de frontier model pra tarefas bem definidas!
